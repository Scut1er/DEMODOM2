# Хаб и карта сезона — как устроено и что можно править

## Поток

```
Главное меню → Продакшн-хаб → [Начать съёмку] → Карта сезона → [Снимать] → Apartment_Pitch → отзывы → Хаб
```

- `Hub.unity` — первая сцена в Build Settings. Внутри экраны: `MainMenu`, `Intro`, `Hub`, `Map`, `SeasonEnd`, `Settings`.
- `Apartment_Pitch` — съёмка одной серии. Можно запускать напрямую из редактора: продолжит сейв
  или начнёт новый сезон и сам возьмёт карты.
- Сейв: `%USERPROFILE%/AppData/LocalLow/DefaultCompany/DEMODOM2/season.json`.
  Сбросить — меню `RealityDirector → Delete Season Save`.

## Продакшн-хаб (экран `Hub`)

| Блок | Что делает |
|---|---|
| `Background` | Сюда кладётся арт виллы. Сейчас — заглушка-цвет. |
| `ZoneCasting / ZoneStudio / ZoneWriters` | Таблички-зоны поверх арта. Двигайте их на нужные места картинки. Клик — открывает зону справа. |
| `ZonePanel` | Описание зоны: «сейчас даёт», «следующий уровень», стоимость, кнопка апгрейда. |
| `RosterPanel` | Участники. Места открываются уровнем Кастинга (2 → 6). |
| `StatsPanel` | Рейтинг (средняя оценка), бюджет, выпуск, тон сезона (драма/трэш/семья). |
| `TasksPanel` | Задачи зрителей (скрыта, если задач нет). |
| `BottomBar` | Колода, Магазин, Настройки, Выход. |
| `DeckPanel` | Окно колоды/магазина поверх хаба. |

Зоны = ветки команды: **Кастинг** — участники, **Съёмочная** — операторы (кадры), **Сценарная** — сценаристы (карты).

## Карта сезона (экран `Map`)

- Данные: `Assets/Data/Map/EpisodeMap.asset` — **правится в инспекторе**, без кода.
- Колонка (`layer`) = номер выпуска (0…5, всего 6). `row`: −1 верх, 0 середина, 1 низ. `offset` — ручной сдвиг.
- `next` — куда можно пойти из узла. Выбирать можно только узлы, связанные с последним снятым.
- Замок: `lockTrack` + `lockLevel` (например, «Монтаж» — Сценарная ур. 2). Если все доступные узлы
  закрыты — они открываются сами (защита от тупика).
- Эффект выбора: `budget` (± кредиты) и `mood` + `toneGain` (сдвиг тона сезона).
- `art` — картинка карточки. Пусто — иконка-заглушка по `kind`.
- Внешний вид узла — префаб `Prefabs/UI/MapNode`. Шаг сетки — поля `origin / layerStep / rowStep` у `MapView`.

## Префабы (`Assets/Prefabs/UI/`)

`HubButton` (все кнопки), `EventCard`, `MapNode`, `ZoneButton`, `CastRow`, `StatsPanel` (один на хаб и карту).

Менять цвета, спрайты, шрифты, двигать и добавлять декор — можно.
**Не ломайте ссылки**: у `*View`-компонентов и `HubFlow` заполнены поля в инспекторе. Пересоздали объект —
перетащите его в то же поле.

## Программистам

- Логика: `Meta/MetaService.cs` (колода/магазин/команда), `Meta/MapService.cs` (карта), данные — `Meta/EpisodeMap.cs`.
- Экраны только отображают модели (`PrepModel`, `CrewInfo`, `StatsModel`).
- Участники для хаба — `Meta/CastRoster.cs` (пока двое из квартиры).
- `PitchUi` ещё содержит старый встроенный экран подготовки — не вызывается, удалить при чистке.
