# Хаб и карта выпуска — как устроено и что можно править

> Геймдизайнеру: всё настраивается в окне **`RealityDirector → Designer Panel`**, подробно — [Designer_Guide.md](Designer_Guide.md).

## Поток

```
Главное меню → Хаб → [Начать] → Карта выпуска → комнаты (съёмка в Apartment_Pitch / событие / маркетинг)
            → Монтаж → эфир → Хаб → следующий выпуск … → итоги сезона
```

- `Hub.unity` — первая сцена в Build Settings. Внутри экраны: `MainMenu`, `Intro`, `Hub`, `Map`, `SeasonEnd`, `Settings`.
- `Apartment_Pitch` — одна комната-съёмка. После неё игрок возвращается на карту выпуска, а не в хаб. Можно запускать напрямую из редактора: продолжит сейв
  или начнёт новый сезон и сам возьмёт карты.
- Сейв: `%USERPROFILE%/AppData/LocalLow/DefaultCompany/DEMODOM2/season.json`.
  Сбросить — меню `RealityDirector → Delete Season Save`. Сейв хранит id контента, не ссылки на ассеты.

## Продакшн-хаб (экран `Hub`)

| Блок | Что делает |
|---|---|
| `Background` | Сюда кладётся арт виллы. Сейчас — заглушка-цвет. |
| `ZoneCasting / ZoneStudio / ZoneWriters` | Таблички-зоны поверх арта. Двигайте их на нужные места картинки. Клик — открывает зону справа. |
| `ZonePanel` | Описание зоны: «сейчас даёт», «следующий уровень», стоимость, кнопка апгрейда. |
| `RosterPanel` | Участники. Места открываются уровнем Кастинга (2 → 6). |
| `StatsPanel` | Рейтинг (средняя оценка), бюджет, выпуск, тон сезона (драма/трэш/семья). |
| `TasksPanel` | Задачи зрителей (скрыта, если задач нет). |
| `BottomBar` | Колода, Магазин, Настройки, Выход. |
| `DeckPanel` | Окно колоды/магазина поверх хаба. |

Зоны = ветки команды: **Кастинг** — участники, **Съёмочная** — операторы (кадры), **Сценарная** — сценаристы (карты).

## Сезон и выпуски — `Assets/Data/SeasonConfig.asset`

| Поле | Что делает |
|---|---|
| `episodes` | Сколько выпусков в сезоне. Между выпусками — хаб. |
| `maps` | Карта для каждого выпуска по порядку (0 — выпуск 1). Выпусков больше — берётся последняя. |
| `startingBudget` | Бюджет в начале сезона. |
| `startingCash` | Нал в начале каждого выпуска (магазин выпуска). |
| `castMax` | Сколько участников в выпуске (места ещё ограничивает уровень Кастинга). |

## Карта выпуска (экран `Map`) — генерируется каждый выпуск

Как в Slay the Spire: один старт, развилки, все пути сходятся в **монтаж**. Готовая карта сохраняется в сейв.
Настройки формы — `Assets/Data/Map/EpisodeMap_Default.asset` (можно сделать несколько и раздать по выпускам):

| Поле | Что делает |
|---|---|
| `floors` | Рядов (комнат по пути) слева направо, включая старт и монтаж. |
| `lanes` | Дорожек по вертикали — максимум комнат в одном ряду. |
| `paths` | Сколько путей прокладывается. Больше путей — больше развилок. |
| `seed` | 0 — новая карта каждый выпуск. Любое число — всегда одна и та же (для теста). |
| `*Weight` | Шансы типов в средних рядах: съёмка, событие, маркетинг. Тип без подходящих комнат не выпадает. |
| `minSpecialFloor` | С какого ряда появляются событие и маркетинг. |
| `guaranteedMarketingFloor` | Ряд, где все комнаты — маркетинг (-1 — нет). |
| `noRepeatSpecial` | Событие не идёт сразу за событием, маркетинг — за маркетингом. |
| `situationBeforeMontage` | Ряд перед монтажом — только съёмки. |
| `opening` / `montage` | Первая и последняя комнаты выпуска. |
| `pool` | Из каких комнат собирать карту. Пусто — все комнаты из `Resources/Content`. |

**Типы комнат:**
- **Съёмка (Situation)** — квартира. Карты выбираются прямо на карте (0..лимит), «Начать съёмку» — сразу в сцену.
- **Событие (Event)** — пока заглушка: комната засчитывается сразу (`HubFlow.RunEvent`).
- **Маркетинг (Marketing)** — пока старый магазин карт; офферы и спонсоры — следующий шаг.
- **Монтаж (Montage)** — всегда последняя. Пока заглушка: выпуск сразу уходит в эфир (`HubFlow.RunMontage`).

## Контент комнат — `Assets/Resources/Content/Rooms/`

Одна комната = один ассет. Новая: ПКМ → `Create → RealityDirector → Rooms → Situation / Event / Marketing / Montage`,
положить в эту папку (любая подпапка) — комната сразу в пуле. Стартовый набор: меню `RealityDirector → Content → Create Default Content`.

| Поле | Что делает |
|---|---|
| `id` | Стабильный id для сейвов. Пусто — из имени ассета. **Не менять** после выхода в игру. |
| `title`, `subtitle`, `description`, `goal`, `icon`, `color`, `art` | Как комната выглядит на карте. |
| `weight` | Шанс среди комнат своего типа. 0 — только если указана напрямую (старт, монтаж). |
| `conditions` | Когда комната может появиться: номер выпуска, каст, бюджет, уровень команды, флаги, тон… Проверяются и при входе — непройденное условие закрывает комнату с пояснением. |
| `uniquePerEpisode` | Не встречается дважды на одном пути. |
| `onEnter` | Эффекты при входе: бюджет, тон, флаги выпуска/сезона, сюжетные теги, временные карты. |

Проверка повторов id: `RealityDirector → Content → Validate Content IDs`.

## Префабы (`Assets/Prefabs/UI/`)

`HubButton` (все кнопки), `EventCard`, `MapNode`, `ZoneButton`, `CastRow`, `StatsPanel` (один на хаб и карту).

Менять цвета, спрайты, шрифты, двигать и добавлять декор — можно.
**Не ломайте ссылки**: у `*View`-компонентов и `HubFlow` заполнены поля в инспекторе. Пересоздали объект —
перетащите его в то же поле.

## Программистам

- Состояние: `SeasonState` (сезон) → `EpisodeState` (выпуск: каст, карта, маршрут, клипы, контракты, флаги, модификаторы).
- Логика выпуска: `Meta/Episode/EpisodeService.cs` (начать/восстановить/закрыть комнату/эфир), карта — `MapGenerator`, `MapService`.
- Условия и эффекты для любого контента: `Meta/Rules/` (`Condition`, `Effect`, `Rules.Check/Apply`).
- Контент: наследники `ContentDefinition` (стабильный `id`), загрузка — `ContentLibrary.All<T>()` из `Resources/Content`.
- Колода/магазин/команда — `Meta/MetaService.cs`.
- Карты продюсера: `PitchContent` строит встроенные, `Meta/Cards/CardLibrary.Merge` накладывает ассеты из `Resources/Content/Cards`
  (тот же id — переопределение, новый id — новая карта). В игре только копии — ассеты не меняются.
- Участники: `Meta/Actors/ActorDefinition` → `CastRoster.All()` (хаб и каст). Квартира пока строит своих двоих в коде.
- Инструменты дизайнера — `Editor/Designer/` (панель, инспекторы, рисовалки условий/эффектов, предпросмотр карты).
- Экраны только отображают модели (`PrepModel`, `CrewInfo`, `StatsModel`).
- Участники для хаба — `Meta/CastRoster.cs` (пока двое из квартиры).
- `PitchUi` ещё содержит старый встроенный экран подготовки — не вызывается, удалить при чистке.
