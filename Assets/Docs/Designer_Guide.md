# Гайд геймдизайнера — что можно настроить без программиста

Всё открывается из одного окна: **`RealityDirector → Designer Panel`**. Для карт и событий — отдельные **`Card Workshop`** и **`Event Workshop`** в том же меню.
Выделили ассет в панели — его настройки открылись в инспекторе. Все поля подписаны по-русски, у каждого есть подсказка (наведите мышь).
Ошибки и забытые поля инспектор показывает жёлтыми/красными плашками прямо под ассетом.

> Правило одно: **`id` не меняем**, после того как контент попал в игру. Сейвы и колода ссылаются на id.
> Название, тексты, числа, арт — меняйте сколько угодно.

---

## 1. Сезон — вкладка «Сезон и карта»

Ассет `Assets/Data/SeasonConfig.asset`.

| Поле | Что значит |
|---|---|
| Выпусков в сезоне | Между выпусками игрок возвращается в хаб. |
| Карты выпусков | Список карт по порядку: 1-я — для выпуска 1, 2-я — для выпуска 2… Не хватило — берётся последняя. |
| Бюджет на старте | Сколько кредитов у игрока в начале сезона. |
| Нал на выпуск | Сколько нала у игрока в начале каждого выпуска (магазин на карте выпуска). |
| HellToken на съёмку | Сколько долларов HellToken ($10) у игрока в каждой съёмке на розыгрыш карт. |
| Каст мин/макс | Сколько участников игрок выбирает в выпуск. Мест ещё ограничивает уровень Кастинга в хабе. |
| Клипов за выпуск / в эфир | Сколько моментов копится за выпуск и сколько идёт в монтаж эфира. |

Внизу инспектора — «Как будет выглядеть сезон»: какая карта у какого выпуска.

## 2. Карта выпуска

Ассеты в `Assets/Data/Map/`. Новая — кнопка «+ Новая карта выпуска» (копирует первую и сразу добавляет в сезон).

**Форма:** рядов (длина пути), дорожек (ширина), путей (сколько развилок), seed (0 — всегда новая карта).
**Шансы типов:** веса съёмки / события / маркетинга в средних рядах.
**Правила:** с какого ряда появляются события и маркетинг, ряд «только маркетинг», запрет повторов подряд, съёмка перед монтажом.
**Комнаты:** старт, монтаж и пул (пусто — все комнаты проекта).

Под настройками — **предпросмотр**: карта перерисовывается сразу, как меняете числа.
- «Другая» — следующий вариант карты.
- «Как будто выпуск №» и «Уровень Кастинга» — проверить комнаты с условиями (например, «Элиминация» с выпуска 2).
- **«Статистика по 200 картам»** — сколько в среднем комнат, доля каждого типа, как часто выпадает каждая комната. Главный инструмент балансировки весов.

## 3. Комнаты — вкладка «Комнаты»

Ассеты в `Assets/Resources/Content/Rooms/`. Положили в папку — комната в игре. Кнопки «+ новая комната» есть у каждого типа.

| Тип | Что это сейчас |
|---|---|
| Съёмка | Квартира, основной геймплей. |
| Событие | Текст и 2–3 выбора с последствиями — см. «Мастерская событий» ниже. |
| Маркетинг | Покупки за нал и спонсорские контракты — список «Предложения» в ассете комнаты (карта, тип, цена, репутация, выплата, удар по отзывам). Пустой список — стандартный набор. |
| Монтаж | Всегда последняя. Пока сразу эфир. |

Поля комнаты:
- **Вид на карте:** заголовок, подзаголовок, описание, цель, иконка, цвет, арт.
- **Вес:** шанс среди комнат своего типа. 0 — только если указана напрямую (старт, монтаж).
- **Условия** — когда комната может появиться. Выбираете тип из списка, остальные поля подстраиваются:
  выпуск не раньше/не позже, бюджет, размер каста, участник в касте, флаги выпуска/сезона, сюжетный тег,
  пройденная комната, уровень команды, тон сезона. Галочка **НЕ** переворачивает условие.
  «Текст, если нельзя» — что увидит игрок на закрытой комнате.
- **Уникальная** — не встречается дважды на одном пути.
- **Эффекты при входе:** бюджет ±, тон сезона, поставить/снять флаг, сюжетный тег, временная карта на выпуск, модификатор следующей съёмки (актёры начнут со стрессом, злостью, грустью или враждой).

Кнопка **▾** рядом с полем подсказывает уже существующие значения (id участников, комнат, карт, флаги из эффектов) — чтобы не было опечаток.

## 3а. События — «Мастерская событий»

Открыть: **`RealityDirector → Event Workshop`** (или кнопка во вкладке «Комнаты» Designer Panel).
Событие — комната карты выпуска: иллюстрация, текст и 2–3 выбора с последствиями. Футажа не даёт — зритель его не видел.
Ассеты — в `Assets/Resources/Content/Rooms/Events/`.

**Режимы окна:**
- **Событие** — список (фильтры: выпадают / выключенные / с риском / с ценой / с проблемами; поиск по тексту) и редактор.
- **Связи** — все сюжетные теги и флаги: какие события и комнаты их ставят и кто их проверяет.
  Красным — условие на то, что никто не ставит; жёлтым — тег, который ни на что не влияет.
- **Обзор** — сколько событий выпадает (по GDD нужно 8–10), доля каждого по весу, риск и цены, проблемы.

**Редактор события сверху вниз:**

| Блок | Поля | Что делает |
|---|---|---|
| Предпросмотр | — | Экран события как в игре, с подставленными именами и закрытыми вариантами. |
| Песочница | Выпуск, кр, нал, Кастинг, сюжетные теги | «Как будто» состояние игры: видно, какие варианты откроются. Кнопки **Успех / Провал** разыгрывают вариант и показывают результат, игра не меняется. |
| На карте выпуска | Заголовок, подзаголовок, подпись, иконка, цвет, иллюстрация | Узел на карте и шапка экрана события. |
| Когда выпадает | Вес, условия, «не повторять на пути» | Как с любой комнатой. Вес 0 — событие выключено. |
| При входе | Эффекты, сюжетные теги | Срабатывают сразу, до выбора. |
| Текст события | Роли, текст | `{актёр}` в любом тексте заменяется именем участника. Роль без участника — случайный из каста (у одного узла карты — всегда один и тот же). |
| Выборы | Кнопка, пояснение | Текст варианта. |
| | Условия, «скрыть, если закрыт» | Закрытый вариант виден с причиной («Нужно 50 нал», «С выпуска 2»), если не скрыт. |
| | Цена кр / нал | Списывается при выборе; не хватает — вариант закрыт. |
| | Шанс успеха, % | 100 — всегда успех. Меньше — игрок видит «шанс 60%», при провале работают блок «Если провал». |
| | Эффекты, текст результата, сюжетные теги | Последствия. Эффекты: бюджет ±, **нал ±**, тон, флаги выпуска/сезона, сюжетный тег, карта до эфира, **карта в колоду навсегда / убрать из колоды**, **модификатор эфира**, **репутация спонсоров ±**. |
| | Минус к бюджету/налу в эффектах | Работает как цена: без денег вариант закрыт («Нужно 15 кр»). С шансом — по худшему исходу. |

**Что игра исполняет из эффектов события** (остальные флаги и теги пока ни на что не влияют — их не проверяет ни одно условие):

| Эффект | Ключ | Что происходит |
|---|---|---|
| Следующая съёмка: актёры начнут с… | `stress`, `anger`, `sadness`, `hostility`, `attraction`, `confidence` | Прибавка к состоянию каста в начале следующей съёмки, по шкале 0–100. |
| Модификатор эфира | `rating` | Оценка эфира, в десятых балла (5 = +0.5). Пустой эфир не двигает. |
| | `pay` | Кр к выплате за эфир. |
| | `sponsorPay` | Кр к выплате спонсора — только если рекламный кадр вышел в эфир. |
| Репутация спонсоров | — | ± к репутации (0–100). |
| Флаг выпуска | `TechPenalty` | Первый кадр следующей съёмки — качеством ниже (плохой звук). |
| | `RevealDiscount` | Следующая карта разоблачения дешевле на $1. |
| | `ProvocationDiscount` | Провокации дешевле на $0.25 всю следующую съёмку. |
| | `CaptureSlotMinus` / `ExtraCaptureSlot` | −1 / +1 слот футажа в следующей съёмке. |

Если все варианты закрыты, игроку покажут «Уйти» — тупика не будет.
Выбор сразу сохраняется: выйти из игры и «переиграть» событие нельзя.

**Проверки:** нет вариантов или текста, роль `{…}` без определения (игрок увидит скобки), вариант без последствий, шанс без описанного провала.
**▶ Проверить** — откроется хаб, и событие сразу появится поверх карты выпуска (результат не сохраняется в сейв).

Новые условия для любых комнат и вариантов: **«Нал выпуска не меньше»**.

## 4. Карты продюсера — «Мастерская карт»

Открыть: **`RealityDirector → Card Workshop`** (или кнопка во вкладке «Карты продюсера» Designer Panel).
Карты — ассеты в `Assets/Resources/Content/Cards/`. Ассет с id встроенной карты меняет её, ассет с новым id — новая карта.

**Три режима окна:**
- **Карточка** — список слева (фильтры: стартовые / магазин хаба / магазин выпуска / спонсоры / негде взять / по тону; поиск по названию, id, тегу) и полный редактор справа.
  Вверху редактора — карта как в игре, «Где взять» и «Что произойдёт» простыми словами.
- **Таблица** — цифры всех карт сразу: цель, два тона, стартовая, цены в кр и нале, спонсор, злость, огонь. Двойной клик по названию — открыть карточку.
- **Обзор** — баланс колоды: сколько карт в каждом источнике и средние цены, распределение тона, цели, какие теги никто не использует, список проблем.

**Кнопки:** «+ Новая карта», «Дублировать», «Удалить» (встроенная карта после удаления ассета вернётся к значениям из кода),
**«▶ Проверить»** — откроется квартира, и выбранная карта будет первой в руке.

**Поля карты** (в инспекторе в этом же порядке). ◇ — данные по GDD, которые квартира пока не читает: они сохраняются и заработают вместе с ядром карт (HellToken, кубики, эмоции — работа кора).

| Блок | Поле | Что делает |
|---|---|---|
| Паспорт | ID | Стабильный id — не менять после выхода карты в игру. |
| | Название | Крупно на карте. |
| | Статус | Черновик / на тесте / готова — для команды. **«Выключена» — карты нет в игре** (ни в колоде, ни в магазинах). |
| | Категория | Открывает карту уровнем Сценаристов: провокация, окружение, хаос/комедия, контроль, спонсор — сразу; социальная, исповедь, управление колодой — ур. 2; раскрытие/секрет — ур. 3. Без категории — открыта сразу. |
| | Теги | На них реагируют участники и по ним оцениваются кадры. «+ тег» показывает, что каждый тег вызывает. |
| | Тон | До двух тонов, каждый +6 к тону сезона. Первый — цвет рамки карты. |
| | Tier ◇, Редкость ◇ | Ступень улучшения (I–III) и редкость. |
| | HellToken $ | Сколько долларов съедает розыгрыш на съёмке, с центами: 0.75. Не хватает — карту не сыграть. |
| Цель | Цель | **Весь дом** — сразу. **Участник** — клик по человеку (можно ограничить чертой). **Объект** — клик по предмету (холодильник, двери; пусто — любой). ◇ **Пара участников, Зона, Карта в руке, Использованная карта** — по GDD; пока квартира играет пару как «участник», остальное — сразу. |
| | Фильтры цели ◇ | Черта есть/нет, эмоция не меньше/не больше, состояние, тег объекта, тег окружения рядом. |
| Описание для игрока | Подсказка | Коротко на карте; показывается и при клике не туда. |
| | Описание ◇ | Полный текст карты. |
| Эффекты / правила | Злость, сек / Поджигает | Работают сейчас: злость цели-участника, огонь цели-объекта. |
| | Эффекты ◇ | Эмоция ±, отношения ±, временное состояние (Drunk, Suspicious…) с длительностью, событие с тегами, позвать актёра, управление колодой (вернуть/взять/найти/удержать карту, цена ±, усилить следующую). |
| Dice effects ◇ | Броски | «Злость +1d6»: кубик d4–d12, количество, прибавка, преимущество/помеха. **Step Up** — кубик растёт на N ступеней, если рядом тег (Alcohol), у цели черта/состояние или эмоция выше порога. Под списком — готовая строка: «Злость +1d6 · d8, если рядом тег окружения «Alcohol»». |
| Environment / Prefab ◇ | Префаб, Id объекта, Живёт | Объект, который карта ставит в мир (id из таблицы, пока префаба нет), и сколько он живёт. |
| Aura ◇ | Радиус, теги, эмоции, кубики, веса поведения | Зона вокруг объекта: эмоции в секунду, ступени кубиков, множители поведения (Shout ×2…). |
| Влияние на Footage ◇ | Теги кадра, ценность, коммерческая | Что получают кадры с этой картой. |
| Sponsor | Продакт-плейсмент, Платит, Отзывы − | Работает сейчас: кр после сцены, отзывы ниже. Бренд ◇ — для контрактов и HellTube. |
| Где взять | Стартовая, Магазин хаба (кр), Магазин выпуска (нал) | Работает сейчас. |
| Special rules / Lifecycle ◇ | Жизненный цикл, Особые правила | Постоянная / одна на выпуск / сгорает / до эфира; удерживается, всегда в стартовой руке, не теряется, сгорает несыгранной, проклятие, занимает Production Slot. |
| Upgrade Tier II / III ◇ | Карта, Крафт, кр | Улучшенная версия — отдельная карта. Кнопка «Создать карту Tier II из этой» сделает копию и свяжет. Крафт: 3 × карта + кр. |
| Вид | Цвет, Арт | Цвет — фон арта и вспышка. Пустой арт у встроенных карт = их иконка из кода. |
| Design intent | Зачем карта | Для команды: какую ситуацию карта должна создавать. |

Таблица мастерской показывает и паспорт (статус, категория, Tier, редкость, HellToken $), фильтры — по статусу, обзор — категории с ценами и редкость.

**Прогноз реакций** под полями: кто из участников и как отреагирует на теги карты (по правилам реакций квартиры).

### Импорт карт из таблицы (.xlsx)

Карты можно вести в Excel/Google Sheets (скачать как .xlsx). Таблица — `Assets/Docs/ONLY_WHAT_MATTERS_Cards_v1.xlsx`.
Импорт: кнопка **«Импорт из таблицы»** в мастерской карт (или Designer Panel → «Карты продюсера», или меню `RealityDirector → Карты: импорт из таблицы`).

- Лист **«Карты»**, строка заголовков с колонками «ID», «Название»… Порядок колонок не важен. Строка = карта, ID = имя ассета.
- Повторный импорт **обновляет** карты по таблице: таблица — главная для своих колонок (паспорт, цель, описание, эффекты, кубики, аура, footage, спонсор, lifecycle, design intent).
- **Не перезаписываются** (задаются только новой карте, дальше правите в Unity): цены в магазинах, тон, цвет, арт, подсказка на карте, злость, выплата спонсора.
- Текст колонок «Фильтры цели», «Эффекты», «Dice», «Aura», «Footage», «Lifecycle», «Upgrade Tier II/III» сохраняется в карте (блок «Из таблицы дизайна» внизу инспектора) — это спецификация для кора.
- Эффекты пишите именами из GDD через «;»: `CreateWorldEvent(Public,Provocation); ModifyEmotion(Anger)`. Кубики: `Anger +1d6; Stress -1d4; Shy: Stress +1d4`.
- После импорта — отчёт: что не удалось разобрать в структуру.
- Спонсорская карта сама получает контракт в комнатах маркетинга.

**Синхронизация с кодом.** Когда программист добавляет карте новое поле или новую встроенную карту, мастерская показывает жёлтую плашку.
«Синхронизировать» допишет в ассеты только недостающее — ваши значения (включая нули) не трогаются.

Ограничения:
- Новая карта работает через общие поля. Уникальная механика (как «Ванная» открывает дверь) — работа кора.
- У `open_bathroom`, `open_bedroom`, `meditation_bell` особое поведение по id — id не трогать.

## 5. Участники — вкладка «Участники»

Ассеты в `Assets/Resources/Content/Characters/`. Нажмите **«Создать стартовых»** — появятся Злой и Добряк.

- **Имя** в хабе.
- **Арт:** портрет или префикс файлов (`zloi` → `zloi_happy`, `zloi_mad`, `zloi_sad`, `zloi_love` в `Resources/Art/Characters`). Инспектор показывает все найденные лица.
- **Черты:** строки под портретом в хабе — видимые черты и строка про скрытую черту.
- **Кастинг:** порядок в списке и в касте выпуска, выключатель «доступен».
- **Главная черта** — по ней квартира выбирает реакции; **скрытая черта** — раскрывается по ходу сезона.

Сейчас из ассетов берутся список участников в хабе и каст выпуска. В самой съёмке (квартира) пока живут только Злой и Добряк:
новые участники попадут туда, когда кор научится собирать их из ассетов.

## 6. Инструменты

- «Создать стартовый набор комнат» — вернёт стандартные комнаты (существующие не перезаписывает).
- «Проверить id» — повторы id и ассеты не в той папке.
- «Удалить сейв сезона» — начать с чистого листа.
