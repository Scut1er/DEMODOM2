# Гайд геймдизайнера — что можно настроить без программиста

Всё открывается из одного окна: **`RealityDirector → Designer Panel`**.
Выделили ассет в панели — его настройки открылись в инспекторе. Все поля подписаны по-русски, у каждого есть подсказка (наведите мышь).
Ошибки и забытые поля инспектор показывает жёлтыми/красными плашками прямо под ассетом.

> Правило одно: **`id` не меняем**, после того как контент попал в игру. Сейвы и колода ссылаются на id.
> Название, тексты, числа, арт — меняйте сколько угодно.

---

## 1. Сезон — вкладка «Сезон и карта»

Ассет `Assets/Data/SeasonConfig.asset`.

| Поле | Что значит |
|---|---|
| Выпусков в сезоне | Между выпусками игрок возвращается в хаб. |
| Карты выпусков | Список карт по порядку: 1-я — для выпуска 1, 2-я — для выпуска 2… Не хватило — берётся последняя. |
| Бюджет на старте | Сколько кредитов у игрока в начале сезона. |
| Каст мин/макс | Сколько участников в выпуске. Мест ещё ограничивает уровень Кастинга в хабе. |
| Клипов за выпуск / в эфир | Сколько моментов копится и сколько пойдёт в финальный монтаж. |

Внизу инспектора — «Как будет выглядеть сезон»: какая карта у какого выпуска.

## 2. Карта выпуска

Ассеты в `Assets/Data/Map/`. Новая — кнопка «+ Новая карта выпуска» (копирует первую и сразу добавляет в сезон).

**Форма:** рядов (длина пути), дорожек (ширина), путей (сколько развилок), seed (0 — всегда новая карта).
**Шансы типов:** веса съёмки / события / маркетинга в средних рядах.
**Правила:** с какого ряда появляются события и маркетинг, ряд «только маркетинг», запрет повторов подряд, съёмка перед монтажом.
**Комнаты:** старт, монтаж и пул (пусто — все комнаты проекта).

Под настройками — **предпросмотр**: карта перерисовывается сразу, как меняете числа.
- «Другая» — следующий вариант карты.
- «Как будто выпуск №» и «Уровень Кастинга» — проверить комнаты с условиями (например, «Элиминация» с выпуска 2).
- **«Статистика по 200 картам»** — сколько в среднем комнат, доля каждого типа, как часто выпадает каждая комната. Главный инструмент балансировки весов.

## 3. Комнаты — вкладка «Комнаты»

Ассеты в `Assets/Resources/Content/Rooms/`. Положили в папку — комната в игре. Кнопки «+ новая комната» есть у каждого типа.

| Тип | Что это сейчас |
|---|---|
| Съёмка | Квартира, основной геймплей. |
| Событие | Пока заглушка (засчитывается сразу). Тексты и выборы — следующий шаг. |
| Маркетинг | Пока магазин карт. Спонсорские контракты — следующий шаг. |
| Монтаж | Всегда последняя. Пока сразу эфир. |

Поля комнаты:
- **Вид на карте:** заголовок, подзаголовок, описание, цель, иконка, цвет, арт.
- **Вес:** шанс среди комнат своего типа. 0 — только если указана напрямую (старт, монтаж).
- **Условия** — когда комната может появиться. Выбираете тип из списка, остальные поля подстраиваются:
  выпуск не раньше/не позже, бюджет, размер каста, участник в касте, флаги выпуска/сезона, сюжетный тег,
  пройденная комната, уровень команды, тон сезона. Галочка **НЕ** переворачивает условие.
  «Текст, если нельзя» — что увидит игрок на закрытой комнате.
- **Уникальная** — не встречается дважды на одном пути.
- **Эффекты при входе:** бюджет ±, тон сезона, поставить/снять флаг, сюжетный тег, временная карта на выпуск, модификаторы.

Кнопка **▾** рядом с полем подсказывает уже существующие значения (id участников, комнат, карт, флаги из эффектов) — чтобы не было опечаток.

## 4. Карты продюсера — вкладка «Карты продюсера»

Ассеты в `Assets/Resources/Content/Cards/`.

Сначала нажмите **«Выгрузить встроенные карты»** — все 9 карт игры появятся ассетами, и их можно править.
- Ассет с id встроенной карты **меняет** её (название, цену, тон, злость…).
- Ассет с **новым** id — **новая карта**. Она в магазине, если есть цена, или в стартовой колоде.

| Поле | Что значит |
|---|---|
| Цель | Объект в квартире / участник / весь дом сразу. |
| Объект | Для цели «объект»: холодильник, дверь ванной, дверь спальни. |
| Только на участника с чертой | Для цели «участник»: например, «Разозлить» играется только на агрессивного. |
| Теги события | На них реагируют участники: Fire, Chaos, Conflict, Misery, Fight, Slap, Crying, Warmth, Hug. «+ тег» — выбрать из списка. |
| Тон карты | Драма / трэш / семья — рамка карты и тон сезона. |
| Злость, сек / Поджигает | Простые эффекты в кадре. |
| Цена / Стартовая | Как карта попадает к игроку. |

Ограничения:
- Новая карта работает через общие поля (цель, теги, тон, злость, поджог). Уникальная механика (как «Ванная» открывает дверь) — это работа кора.
- У `open_bathroom`, `open_bedroom`, `meditation_bell` особое поведение по id — id не трогать.
- Тег, которого нет в списке, участники пока не поймут — инспектор предупредит.

## 5. Участники — вкладка «Участники»

Ассеты в `Assets/Resources/Content/Characters/`. Нажмите **«Создать стартовых»** — появятся Злой и Добряк.

- **Имя, архетип, био.**
- **Арт:** портрет или префикс файлов (`zloi` → `zloi_happy`, `zloi_mad`, `zloi_sad`, `zloi_love` в `Resources/Art/Characters`). Инспектор показывает все найденные лица.
- **Черты:** видимые (строки в хабе), главная черта (для реакций), скрытая черта и что видно до раскрытия.
- **Кастинг:** порядок в списке, доступен ли, вес для будущего выбора каста.

Сейчас из ассетов берутся список участников в хабе и каст выпуска. В самой съёмке (квартира) пока живут только Злой и Добряк:
новые участники попадут туда, когда кор научится собирать их из ассетов.

## 6. Инструменты

- «Создать стартовый набор комнат» — вернёт стандартные комнаты (существующие не перезаписывает).
- «Проверить id» — повторы id и ассеты не в той папке.
- «Удалить сейв сезона» — начать с чистого листа.
