# Звук и музыка — план

Статус: ✅ есть запись · 🟡 есть, но синтез/заглушка (заменить) · ❌ нет совсем.
Приоритет: **P1** — до сдачи джема, **P2** — если успеем, **P3** — на будущее.

## Технические требования (чтобы файлы легли без правок кода)

- Эффекты: `.ogg` или `.wav`, **моно**, 44.1 kHz, короткие (0.05–1.5 с), без тишины в начале.
- Музыка: `.ogg`, стерео, 44.1 kHz, ~-14 LUFS; петли — **бесшовные** (проверить стык).
- Эффекты кладём в `Assets/Resources/Sfx/` с **именем из таблицы** (колонка «файл») — код подхватит сам.
  Варианты одного звука: `slap0…slap4` — так уже работает для ударов; так же можно `cry0…`, `laugh0…`.
- Музыку кладём в `Assets/Resources/Music/` (система музыки будет — см. ниже).
- **Каждый файл — строка в `CREDITS.txt`**: название, автор, ссылка, лицензия. Без этого не берём.
- Лицензии: лучше **CC0** / Pixabay License (без указания авторства). CC-BY — можно, но обязательно в титры.
  Не брать: CC-NC (некоммерческая) сомнительна для публикации, музыку с YouTube, «free» без лицензии.

## 1. Музыка

| Где | Настроение | Темп | Петля | Приоритет |
|---|---|---|---|---|
| Главное меню | «заставка шоу»: яркий, гламурный, чуть пародийный | средний | да | P1 |
| Продакшн-хаб / карта | лаунж у бассейна, расслабленно, вечерняя вилла | 90–110 | да | P1 |

| Съёмка (хаос: пожар/драка) | тот же трек, но напряжённее — или отдельный тревожный слой | 130+ | да | P2 |
| Отзывы зрителей | короткий джингл-«итоги» (2–4 с) | — | нет | P1 |
| Хорошая оценка / плохая | два стингера: «ура» и «провал» (1–3 с) | — | нет | P2 |
| Финал сезона (3 концовки) | драма / трэш / семья — по треку на тон, или один торжественный | — | нет | P2 |
| Интро | «вступительная заставка реалити» 5–10 с | — | нет | P3 |

**Идея для единого стиля:** вся музыка — «саундтрек дешёвого реалити»: синт-поп/лаунж в хабе, комедийные
пиццикато на съёмке, пафосные струнные в финале. Контраст пафоса и бытовухи = шутка.

## 3. Что сделает код (программисты)

- **Система музыки**: трек на экран (меню / хаб / съёмка / отзывы), плавные переходы, отдельная громкость
  музыки в настройках. Файлы просто кладутся в `Resources/Music/`.
- Подхват новых эффектов по имени файла (как сейчас `slap0…4`) — варианты выбираются случайно.
- Привязка: смех/«ооо» на драку и слёзы в кадре, аплодисменты/«бууу» на итог оценки, стингер на раскрытие черты.

## 4. Где искать эффекты

- **Kenney.nl** — CC0, UI и игровые (уже используем).
- **freesound.org** — огромная база; фильтр *License: Creative Commons 0*. Для CC-BY — в титры.
- **Pixabay Sound Effects** — без указания авторства; поиск `laugh track`, `audience ooh`, `applause`, `boo`.
- **Sonniss GDC Game Audio Bundle** — профессиональные пакеты, роялти-фри.
- **OpenGameArt.org** — проверять лицензию у каждого файла.
- **jsfxr / ChipTone** — сгенерировать UI-звуки самим (права наши).
- Записать самим на телефон (крики, смех, «ооо») — быстро и смешно, прав никаких не нужно.
